# GTA VI Countdown — виджет для iPhone

Таймер до выхода GTA VI на PS5 в польском PS Store, со временем по Москве.

**Релиз:** 19.11.2026, 00:00 по Варшаве (CET) = **19.11.2026, 02:00 МСК**.
Rockstar открывает доступ в полночь по местному времени каждого региона.

## Установка
1. Установите бесплатное приложение **Scriptable** из App Store.
2. В Scriptable нажмите «+», вставьте код из `GTA6-Countdown.js` и назовите скрипт `GTA6 Countdown`.
3. Добавьте виджет на экран: долгое нажатие на пустом месте → «+» → Scriptable → выберите размер (маленький или средний).
4. Долгое нажатие на виджет → «Изменить виджет» → Script: `GTA6 Countdown`.

Можно добавить и на экран блокировки: подходят виджеты «прямоугольный», «круглый» и «строка над часами».

Таймер тикает каждую секунду, его обновляет сама iOS. После релиза виджет покажет «Уже вышла! 🎮».
